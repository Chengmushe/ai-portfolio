01数据与分析

Ask 问数 Agent ↗

让业务团队直接询问销售、产品等指标，同时看清数字的来源和计算口径。

业务背景
临时问数依赖跨表查询和人工解释，业务人员需要更快获取可信的指标结果。
方案实现
负责问题澄清、指标匹配与查询链路，串联 Data Skills、Wren 和只读 MySQL；接入身份与 PostgreSQL 任务记录，通过流式交互展示进度，并将回答关联查询条件和原始数据。
  • Agent
  • Wren
  • MySQL
  • PostgreSQL
02客户洞察

独立 VOC 客服服务 ↗

把分散的客户反馈整理成可查询、可复盘的分析结果。

业务背景
客服与产品团队需要按月份、产品和来源追踪高频问题，并定期形成一致口径的分析报告。
方案实现
负责反馈、标签结果和标签明细的三表快照与独立存储；统一问答和报表的数据口径，串联反馈查询、固定报告与 Word 导出。
  • 数据快照
  • SQL
  • 报告生成
03服务质量

海外客服质检 Agent ↗

让质检结论能回到原始会话，也能进入申诉与复核流程。

业务背景
海外客服会话持续增加，管理人员需要按统一标准检查响应时长、沟通方式与处理步骤。
方案实现
负责会话接入、标准管理、响应时间计算和模型评分；将结果与原始对话关联，并设计申诉、复核、通知及任务状态追踪。
  • Agent
  • 异步任务
  • 会话处理
