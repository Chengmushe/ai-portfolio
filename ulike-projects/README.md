# 由莱 AI 项目前端原型

本目录是作品集网站的 22 个项目原型。每个页面都有业务化的列表、详情、工作台标签与操作草稿。演示记录和会话仅存在浏览器 localStorage；首页和每个原型顶部都明确标注“未接入数据库与 API”。合成样例不是实时生产数据。

## 接入方式

- `connections.js`：为项目填写受控 HTTPS 后端网关地址；留空时明确显示未接入。
- `api.js`：项目级健康、列表、写入接口合同及 `request(id, kind, options)` 适配层。
- `prototypes.js`：前端原型数据和交互视图。接入真实服务时，在这里将合成样例替换为经过授权的接口响应。
- 数据库密码、模型密钥、OA 与飞书凭据只存放在后端。GitHub Pages 静态页面不能直连数据库，也不应保存这些凭据。

请先让后端网关处理身份、权限、数据范围、跨域与错误状态，再填写连接地址。配置地址不会自动把原型变成真实业务：各项目的接口路径、请求体和数据映射还需按对应服务合同逐项完成验收。未接入时，上传、生成、同步、部署、真实预订与通知都不可执行。
