# AI Projects · GitHub Pages

在线体验：https://chengmushe.github.io/ai-portfolio/

智能旅行助手支持在“AI 设置”中填写自己的 API Key、Base URL 和模型名称，由浏览器直接调用兼容 Chat Completions 的服务，生成任意城市行程并自由修改。接口需允许浏览器 CORS；默认仅在当前标签页保存 Key，勾选后才持久保存于本浏览器。Key 不上传至仓库。未配置时可体验四城离线行程。

行程和草稿保存在当前浏览器；清除网站数据会删除本地记录。GEO 品牌评估为预置示例；其他项目的远程模型、进程管理、消息渠道和真实文章发布需要单独部署后端。此仓库不包含实际密钥、用户数据库或后端服务。

发布：Settings → Pages → Deploy from a branch → main / (root)。
